Код представляет собой программную реализацию математической модели нестационарного температурного поля в плазменном разряде, описываемого системой связанных уравнений в частных производных. 

## Ключевые аспекты:

### 1. **Физическая модель**
Уравнения системы:
1. **Энергетическое уравнение** (параболическое):
```math
c(T)\frac{\partial T}{\partial t} = \frac{1}{r}\frac{\partial}{\partial r}\left(r\lambda(T)\frac{\partial T}{\partial r}\right) + \sigma(T)E^2 - q(r)
```
2. **Уравнение переноса излучения** (эллиптическое):
```math
\frac{1}{r}\frac{d}{dr}\left(\frac{r}{k(T)}\frac{du}{dr}\right) = 3k(T)(u - u_p(T))
```
3. **Связь с электрическим полем**:
```math
E = \frac{I(t)}{2\pi\int_0^R \sigma(T) r dr}
```

### 2. **Численный метод**
- **Пространственная дискретизация**: 
  - Сетка с `N` узлами по радиусу `r ∈ [0, R]`
  - Шаг `h = R/(N-1)`
- **Временная дискретизация**:
  - Неявная схема для устойчивости
  - Шаг времени `τ = 1e-7` сек

- **Метод прогонки (TDMA)**:
  Решение трехдиагональных систем для уравнений:
  - алгоритм Томаса

### 3. **Ключевые функции**
- **solve_u()**:
  Строит СЛАУ для уравнения переноса излучения:
  ```math
  \frac{1}{h^2 k_i}(u_{i-1} - 2u_i + u_{i+1}) - 3k_i u_i = -3k_i u_p(T_i)
  ```
  Граничные условия:
  - На оси симметрии: `du/dr|_0 = 0`
  - На стенке: `-3k(R) du/dr|_R = 0.39 u(R)`

- **solve_T()**:
  Дискретизация уравнения теплопроводности:
  ```math
  \frac{T_i^{new} - T_i}{τ} = \frac{λ_i}{h^2}\left(T_{i-1}^{new} - 2T_i^{new} + T_{i+1}^{new}\right) + \frac{σ_i E^2 - q_i}{c_i}
  ```

### 4. **Вывод формул (на примере уравнения переноса)**
Исходное уравнение:
```math
\frac{1}{r}\frac{d}{dr}\left(\frac{r}{k}\frac{du}{dr}\right) = 3k(u - u_p)
```
Дискретизация:
1. Умножаем на `r` и интегрируем по контрольному объему:
   ```math
   \int_{r_i}^{r_{i+1}} \frac{d}{dr}\left(\frac{r}{k}\frac{du}{dr}\right) dr = \int_{r_i}^{r_{i+1}} 3k r (u - u_p) dr
   ```
2. Применяем теорему Остроградского-Гаусса:
   ```math
   \left.\frac{r}{k}\frac{du}{dr}\right|_{i+1/2} - \left.\frac{r}{k}\frac{du}{dr}\right|_{i-1/2} = 3k_i r_i h (u_i - u_{p,i})
   ```
3. Аппроксимируем производные:
   ```math
   \frac{r_{i+1/2}}{k_{i+1/2}} \frac{u_{i+1} - u_i}{h} - \frac{r_{i-1/2}}{k_{i-1/2}} \frac{u_i - u_{i-1}}{h} = 3k_i r_i h (u_i - u_{p,i})
   ```

### 5. **Особенности реализации**
- **Интерполяция коэффициентов**:
  ```python
  k_interp = interp1d(T_k, k_table, kind='cubic')
  ```
  Кубическая интерполяция обеспечивает гладкое изменение коэффициентов.

- **Учет граничных условий**:
  - На оси (`r=0`): симметрия, производная равна нулю
  - На стенке (`r=R`): баланс потоков тепла и излучения

- **Итерационный процесс**:
  Последовательное обновление:
  1. Ток `I(t)`
  2. Электрическое поле `E`
  3. Плотность излучения `u(r)`
  4. Температура `T(r)`

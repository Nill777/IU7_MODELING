## 🎯 Метод Галеркина
### Обоснование вычисления коэффициентов методом Галеркина

#### 1. Математическая основа
Метод Галеркина основан на ортогональности невязки к базисным функциям. Для уравнения:

$$ Lu = f $$

где $L = \frac{d^2}{dx^2} - 2x \frac{d}{dx} + 2$ - дифференциальный оператор, приближенное решение ищем в виде:

$$ u_n(x) = g(x) + \sum_{k=1}^n c_k \varphi_k(x) $$

Здесь:
- $g(x) = \frac{x^2}{2}$ - функция, точно удовлетворяющая неоднородным граничным условиям:
  - $g(0) = 0$
  - $g'(1) = 1$
- $\varphi_k(x) = x^k(1-x)$ - базисные функции, удовлетворяющие однородным граничным условиям:
  - $\varphi_k(0) = 0$
  - $\varphi_k'(1) = 0$

#### 2. Формирование системы уравнений
Невязка $R(x) = Lu_n - f$. Условие ортогональности:

$$ \int_0^1 R(x) \varphi_j(x) dx = 0, \quad j = 1,...,n $$

После подстановки:

$$ \int_0^1 \left[ L\left(g(x) + \sum c_k \varphi_k\right) - f \right] \varphi_j dx = 0 $$

#### 3. Конкретные вычисления
Для оператора $L$:

$$ a_{ij} = \int_0^1 \left[ \varphi_j'' - 2x \varphi_j' + 2\varphi_j \right] \varphi_i dx $$

Правая часть, учитывая $Lg = 1 - 2x \cdot x + 2 \cdot \frac{x^2}{2} = 1 - x^2$:

$$ b_i = \int_0^1 (f - Lg) \varphi_i dx = \int_0^1 (x - (1 - x^2)) \varphi_i dx $$

**Итоговая система:**
$$ A\vec{c} = \vec{b} $$
где:
- $A$ - матрица элементов $a_{ij}$
- $\vec{b}$ - вектор $b_i$
- $\vec{c}$ - искомые коэффициенты

## 🎯 Разностная схема для уравнения $u'' - 2x u' + 2u = x$

1. **Исходное уравнение:**
   ```math
   u'' - 2x u' + 2u = x
   ```

2. **Аппроксимация производных:**
   - Вторая производная (центральная разность):
     ```math
     u''(x_i) \approx \frac{u_{i+1} - 2u_i + u_{i-1}}{h^2}
     ```
   - Первая производная (центральная разность):
     ```math
     u'(x_i) \approx \frac{u_{i+1} - u_{i-1}}{2h}
     ```

3. **Подстановка в уравнение:**
   ```math
   \frac{u_{i+1} - 2u_i + u_{i-1}}{h^2} - 2x_i \cdot \frac{u_{i+1} - u_{i-1}}{2h} + 2u_i = x_i
   ```
   
   После упрощения:
   ```math
   \left(\frac{1}{h^2} + \frac{x_i}{h}\right) u_{i-1} + \left(-\frac{2}{h^2} + 2\right) u_i + \left(\frac{1}{h^2} - \frac{x_i}{h}\right) u_{i+1} = x_i
   ```

4. **Коэффициенты разностной схемы:**
   - `A[i] = 1/h² + x_i/h` (коэффициент при $u_{i-1}$)
   - `B[i] = -2/h² + 2` (коэффициент при $u_i$)
   - `C[i] = 1/h² - x_i/h` (коэффициент при $u_{i+1}$)
   - `F[i] = x_i` (правая часть уравнения)


5. **Аппроксимация производной левой разностью:**
   ```math
   u'(x_i) \approx \frac{u_i - u_{i-1}}{h}
   ```
   Начальное условие из лабораторной:
   ```math
   u'(x_i) = 1
   ```
   После упрощения:
   ```math
   -\frac{1}{h} u_{N-1} + \frac{1}{h} u_N = 1
   ```
   Отсюда:
   - `A[-1] = -1/h` (коэффициент при $u_{i-1}$),
   - `B[-1] = 1/h` (коэффициент при $u_i$),
   - `F[-1] = end` (правая часть).


## 🎯 Суть метода прогонки
Алгоритм состоит из двух этапов:
1. **Прямой ход** — вычисление прогоночных коэффициентов $\alpha_i$ и $\beta_i$.
2. **Обратный ход** — нахождение решения $u_i$ с использованием $\alpha_i$ и $\beta_i$.

### **Рекуррентные формулы для $i = 1, \dots, N-1$**

- На каждом шаге выражаем $u_i$ через $u_{i+1}$:
   ```math
  u_i = \alpha_{i+1} u_{i+1} + \beta_{i+1}
   ```
- Коэффициенты вычисляются так:
   ```math
  \alpha_{i+1} = \frac{-C[i]}{A[i] \alpha[i] + B[i]}
   ```
   ```math
  \beta_{i+1} = \frac{F[i] - A[i] \beta[i]}{A[i] \alpha[i] + B[i]}
   ```

### Нахождение $u_N$
- Для $i = N$ (последнее уравнение $-\frac{1}{h} u_{N-1} + \frac{1}{h} u_N = 1$):
  - Подставляем $u_{N-1} = \alpha_N u_N + \beta_N$:
   ```math
    -\frac{1}{h} (\alpha_N u_N + \beta_N) + \frac{1}{h} u_N = 1.
   ```
  - Решаем относительно $u_N$:
   ```math
    u_N = \frac{1 + \frac{\beta_N}{h}}{\frac{1}{h} - \frac{\alpha_N}{h}} = \frac{h + \beta_N}{1 - \alpha_N}.
   ```

Последняя строка системы задаётся как:
   ```math
    A[N] u_{N-1} + B[N] u_N = F[N]
   ```

Для правого краевого условия:
- $A[N] = -\frac{1}{h}$ (коэффициент при $u_{N-1}$),
- $B[N] = \frac{1}{h}$ (коэффициент при $u_N$),
- $F[N] = 1$ (правая часть).

Подставляем $u_{N-1} = \alpha_N u_N + \beta_N$:
   ```math
    A[N] (\alpha_N u_N + \beta_N) + B[N] u_N = F[N]
   ```
   ```math
    (A[N] \alpha_N + B[N]) u_N = F[N] - A[N] \beta_N
   ```
   ```math
    u_N = \frac{F[N] - A[N] \beta_N}{B[N] + A[N] \alpha_N}
   ```

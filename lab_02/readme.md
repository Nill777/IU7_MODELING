# Лабораторная работа №2

## Цель
Получение навыков разработки  алгоритмов решения задачи Коши при реализации моделей, построенных  на системе  ОДУ, с использованием метода  Рунге-Кутта 2-го и 4-го порядков точности.

## Описание
В лабораторной работе идет речь о **трубке с плазмой**, в качестве задачи предлагается решить краевую задачу, методами решения задачи Коши. 

В задании дано два варианта исходных данных для **k(r)** при решении задачи при помощи чисел двойной точности на python не хватает точности для решения второго варианта. 

Была предпринята попытка развернуть вычисления и идти в обратном напрвлении (справа налево) к результатам не привело(. Поэтому программа была полностью переписана на длинную арифметику. 

## Исследование
50 порядков достаточно для решения с предоставленными наборами **k(r)**. Исследования проводили на **втором** варианте набора **k(r)**.

Из того что мы получили, шаг в методе **Рунге-Кутты** оказывает крайне малое влияние на точность вычислений (70 или 1000), различие будет в 6 порядке, что для правой границы, что для экстремума.

Требуемая точность для корректных вычислений 47 порядков, если зажать сильнее интервал **chi = [0.9, 1.0]**, то достаточно будет 46 порядков.

Если не зажимать **chi = [0.0, 1.0]**, а увеличивать количество шагов для метода **Рунге-Кутты** результата не будет, количество необходимых порядков снижено не будет, только дольше будут производиться вычисления.
